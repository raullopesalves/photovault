# Screenshot provenance

These images were captured from Photo Vault 0.17.0 using `scripts/e2e-smoke.mjs` against a disposable library. The script creates abstract landscape illustrations and synthetic filenames, dates and albums. It does not open the maintainer's library. Temporary data was placed below a generic `C:\tmp\portfolio-demo` folder; no personal paths, faces, account names, real photographs or real location metadata appear in the selected screenshots.

- `photos.png`: chronological grid, scrolled to the synthetic 2023 collection.
- `viewer.png`: one generated illustration in the photo viewer.
- `albums.png`: albums created by the test fixture.

These images demonstrate layout and workflow, not AI quality or real-world library performance.
